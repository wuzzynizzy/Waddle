Meet your new web sidekick

More than a proxy.
A browser with a route.

Waddle brings the useful bits together: a self-feeding proxy pool, an address bar that feels familiar, and controls that stay yours.

Only the route you chose

No direct mode hiding in a setting. Waddle refuses a page if it cannot reach it through a working proxy.

DIRECT FALLBACK OFF

Routes that stack

Chain up to 16 proxies. Only the exit connects to the site; Waddle automatically harvests sources, tests candidates, and rechecks working exits.

More knobs. Still yours.

Stack carefully.
Keep it changeable.

Stack up to 64 manual DoH resolvers and 16 proxy hops. Server config, browser-local data, and source lists are portable; choose the pool profile and limits that fit your machine.

Ask one. Or compare.

3 / 64 in stack

If one resolver is slow or unavailable, the next can answer through the same proxy route.

Small-server friendly

Keep the penguin nimble.

The small profile reduces background pool work and cache sizes. Launchers default to a 320 MB V8 heap limit, but total memory depends on workload and has not been benchmarked. Page rendering, suggestions and your library stay in your browser.

See the resource knobs ↗

More hops and resolver checks can add latency and failure points. Practical ceilings and the small-server profile limit background work, but actual resource use still depends on your host and workload.
